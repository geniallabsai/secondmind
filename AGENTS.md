# AGENTS.md

Este repositório (e qualquer vault inicializado por ele) segue o protocolo
**SecondMind**: vault Obsidian como memória persistente de agentes de IA.

- Entrada da skill: `SKILL.md` (5 fases: ORIENTAR → RECORDAR → ATUAR → CAPTURAR → FECHAR)
- Bloco autossuficiente para prompt: `BOOT.md`
- Estrutura do vault e leis: `SKILL.md` + `protocols/`
- Instalação por agente: `agents/`

Antes de começar ou terminar qualquer trabalho num vault SecondMind, siga
as 5 fases de `SKILL.md`. No fim de cada sessão, o arquivo de resumo em
`01-sessions/` é obrigatório — é o contrato pelo qual o próximo agente
(qualquer que seja) retoma o contexto sem reescrever a história.
