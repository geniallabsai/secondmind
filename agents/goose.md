# Adapter: Goose (Block)

O Goose descobre skills em `~/.config/goose/skills/<skill>/SKILL.md`.

1. Copie o pacote para `~/.config/goose/skills/secondmind/` mantendo o
   `SKILL.md` na raiz dessa pasta.
2. Defina `VAULT=/caminho/MeuVault` na config da extensão ou no system prompt.
3. Garanta permissão de leitura/escrita no vault.
4. Teste: `evals/golden-session.md`.
