# Adapter: Windsurf

O Windsurf lê regras de projeto em `.windsurf/rules/`.

1. Crie `.windsurf/rules/secondmind.md` com `BOOT.md` + variáveis no topo.
2. Alternativa global: painel de Global Memory → cole `BOOT.md` (vale para
   todos os projetos).
3. Libere acesso aos arquivos do workspace nas configurações.
4. Teste: `evals/golden-session.md`.
